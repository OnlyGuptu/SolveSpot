Q1

Add two 4-digit numbers using the steps we have written down. Make sure you follow the steps precisely; do not perform any action that is not explicitly mentioned. Are you able to obtain the correct result?

Answer: Let's add 4567 and 8924 using the algorithm:
1. Align right to left:
  4567
+ 8924
2. Rightmost digits: 7 + 4 = 11. More than 10. Write 1. Carry = 1.
3. Next column (tens): 6 + 2 + 1 (carry) = 9. Less than 10. Write 9. Carry = 0.
4. Repeat (hundreds): 5 + 9 + 0 = 14. More than 10. Write 4. Carry = 1.
5. Repeat (thousands): 4 + 8 + 1 (carry) = 13. More than 10. Write 3. Carry = 1.
6. No more digits on left. Step 5: Carry is 1, so write 1 to the left.
Result: 13491. Yes, the correct result is obtained.

Q2

What happens if you add a 5-digit number to a 3-digit number. Do our steps handle this situation correctly?

Answer: Our steps, as strictly written, do not explicitly mention what to do when one number runs out of digits while the other still has digits left. To handle this correctly, we must assume that the missing columns of the 3-digit number are filled with leading zeros so that the "add the two digits" instruction in Step 3 still applies.

Q3

Why is it important to align the columns from right to left?

Answer: Aligning from right to left ensures that digits of the same place value (units with units, tens with tens, hundreds with hundreds) are added together. If aligned left to right, we might mistakenly add thousands to hundreds or tens, resulting in an incorrect sum.

Q4

In Step 3, why cannot the value of carry be more than 1?

Answer: The maximum single digit is 9. If we add two 9s and a previous carry of 1, the maximum possible sum in any column is $9 + 9 + 1 = 19$. Since 19 is less than 20, the tens digit (which becomes the new carry) can never exceed 1.

Q5

What happens if we do not include the fifth step in the algorithm above? Give examples where the algorithm will work correctly and where it will fail to work.

Answer: Step 5 adds the final leftover carry to the front of the answer.
Where it works correctly: It works for $32 + 45 = 77$. The final column is $3 + 4 = 7$ (carry 0). Since carry is not 1, Step 5 wouldn't trigger anyway.
Where it fails: It fails for $85 + 42$.
- Units: $5 + 2 = 7$, carry = 0.
- Tens: $8 + 4 + 0 = 12$. Write 2, carry = 1.
Without Step 5, the algorithm ends and gives the answer as 27 instead of 127.

Q1

Suppose List 1 and List 2 are two lists of numbers in increasing order.
(i) Write an algorithm to find elements in List 1 that are not present in List 2.
(ii) Write an algorithm to find elements in List 2 that are not present in List 1.

Answer:
(i) Algorithm for elements in List 1 not in List 2:
1. Start with an empty list called 'difference-list'.
2. For each number x in List 1:
    If x does not appear in List 2, add x to 'difference-list'.
3. Report 'difference-list'.

(ii) Algorithm for elements in List 2 not in List 1:
1. Start with an empty list called 'difference-list'.
2. For each number y in List 2:
    If y does not appear in List 1, add y to 'difference-list'.
3. Report 'difference-list'.

Q2

Describe an algorithm to compute the least common multiple (lcm) of two numbers.

Answer:
Algorithm to find lcm(m, n):
1. Set a variable 'multiple' to the value of the larger number between m and n.
2. Check if 'multiple' is divisible by the smaller number.
3. If it is divisible, report 'multiple' as the lcm.
4. If it is not divisible, add the larger number to 'multiple' and repeat Step 2.

Q3

Divisors occur in pairs. For instance, the divisors of 18 are (1, 18), (2, 9) and (3, 6).
(i) If we write out divisors in pairs, how many numbers do we have to examine between 1 and n to find all the divisors of n?
(ii) If we list out the divisors in pairs, will our gcd algorithm still work in the manner we have described?

Answer:
(i) We only need to examine numbers from 1 up to the square root of n (i.e., $\sqrt{n}$). For every divisor $d \le \sqrt{n}$, its pair is $n/d$.
(ii) The original gcd algorithm assumes the generated divisor lists are in strictly increasing order to simply pick the "rightmost" element at the end. If we append both $d$ and $n/d$ at the same time, the list won't be strictly increasing unless we sort it afterwards. If we sort it, the algorithm works perfectly; if not, we must modify the last step to search the entire common-divisors list for the maximum value rather than just taking the rightmost element.

Q1

How would our original algorithm change if we computed the divisors of n by examining the numbers from 1 to n in reverse order, from n down to 1?

Answer: The list of divisors would be generated in strictly decreasing order instead of increasing order. Consequently, the list of common divisors would also be in decreasing order. Therefore, Step 5 of the original algorithm would need to change: instead of reporting the rightmost element (which would now be 1), it must report the leftmost element (the first and largest common divisor found).

Q2

What about the last algorithm described above? What happens when we look at common divisors starting from $min(m, n)$ and work backwards to 1?

Answer: If we start from $min(m, n)$ and work backwards to 1, the very first common divisor we encounter will be the greatest common divisor. This drastically improves efficiency because we can stop the loop immediately upon finding the first number that divides both m and n, rather than scanning all the way to $min(m,n)$ and constantly updating the most-recent-common-divisor.

Q1

Compute the following using the improved version of Euclid's algorithm (Āryabhaṭa's Division Algorithm).

  • (i) gcd(375, 825)
  • (ii) gcd(51000, 81000)
  • (iii) gcd(1789287, 237656)
  • (iv) gcd(2587392, 157656)

Answer: Using repeated division to find the remainder ($m \mod n$):
(i) gcd(375, 825):
825 ÷ 375 = 2 remainder 75.
375 ÷ 75 = 5 remainder 0.
gcd = 75.

(ii) gcd(51000, 81000):
81000 ÷ 51000 = 1 remainder 30000.
51000 ÷ 30000 = 1 remainder 21000.
30000 ÷ 21000 = 1 remainder 9000.
21000 ÷ 9000 = 2 remainder 3000.
9000 ÷ 3000 = 3 remainder 0.
gcd = 3000.

(iii) gcd(1789287, 237656):
1789287 ÷ 237656 = 7 remainder 125695.
237656 ÷ 125695 = 1 remainder 111961.
125695 ÷ 111961 = 1 remainder 13734.
111961 ÷ 13734 = 8 remainder 2089.
13734 ÷ 2089 = 6 remainder 1200.
2089 ÷ 1200 = 1 remainder 889.
1200 ÷ 889 = 1 remainder 311.
889 ÷ 311 = 2 remainder 267.
311 ÷ 267 = 1 remainder 44.
267 ÷ 44 = 6 remainder 3.
44 ÷ 3 = 14 remainder 2.
3 ÷ 2 = 1 remainder 1.
2 ÷ 1 = 2 remainder 0.
gcd = 1.

(iv) gcd(2587392, 157656):
2587392 ÷ 157656 = 16 remainder 64896.
157656 ÷ 64896 = 2 remainder 27864.
64896 ÷ 27864 = 2 remainder 9168.
27864 ÷ 9168 = 3 remainder 360.
9168 ÷ 360 = 25 remainder 168.
360 ÷ 168 = 2 remainder 24.
168 ÷ 24 = 7 remainder 0.
gcd = 24.

Q2

Assume that $m \ge n$. Verify that $d$ divides $m$ and $n$ if and only if $d$ divides both $n$ and $m \mod n$.

Answer: Let $m \mod n = r$. By the division algorithm, we can write $m = qn + r$, where $q$ is the quotient. Therefore, $r = m - qn$.
Part 1 (Forward): Assume $d$ divides $m$ and $n$. Then $m = ad$ and $n = bd$ for some integers $a, b$. Substituting these into $r = m - qn$, we get $r = ad - q(bd) = d(a - qb)$. Since $(a - qb)$ is an integer, $d$ divides $r$ (which is $m \mod n$). So, $d$ divides both $n$ and $m \mod n$.
Part 2 (Backward): Assume $d$ divides $n$ and $r$ ($m \mod n$). Then $n = xd$ and $r = yd$ for some integers $x, y$. Substituting these into $m = qn + r$, we get $m = q(xd) + yd = d(qx + y)$. Since $(qx + y)$ is an integer, $d$ divides $m$. So, $d$ divides both $m$ and $n$.

Q3

Write an algorithm prime(n) to check if n is prime.

Answer:
Algorithm prime(n):
1. Let list-of-divisors be the list obtained by computing divisors(n).
2. Count the number of elements in list-of-divisors.
3. If the count is exactly 2, report "Prime".
4. Otherwise, report "Not Prime".

Q4

Write an algorithm primedivisors(n) to compute the list of divisors of n that are prime numbers.

Answer:
Algorithm primedivisors(n):
1. Let list-of-divisors be the list obtained by computing divisors(n).
2. Start with an empty list called 'prime-divisors-list'.
3. For each number x in list-of-divisors:
    Execute prime(x) (from Exercise 3).
    If prime(x) reports "Prime", add x to 'prime-divisors-list'.
4. Report 'prime-divisors-list'.

Q5

We can also find the gcd of two numbers by computing prime factorisation of both the numbers. Try to write an algorithm to compute the prime factorisation of a number.
(i) The prime factorisation of 180 is $2^2 \times 3^2 \times 5^1$. How would you represent this?
(ii) How would you compare the prime factorisations of two numbers?

Answer:
Algorithm for Prime Factorisation of n:
1. Create an empty list called 'factors'.
2. Set $d = 2$ (the smallest prime).
3. While $n > 1$:
    If $n$ is divisible by $d$:
        Add $d$ to 'factors'.
        Set $n = n / d$.
    Else:
        Increase $d$ by 1.
4. Report 'factors'.

(i) Representation: It can be represented as a list of base-exponent pairs (e.g., [(2, 2), (3, 2), (5, 1)]) or just a flat list of primes [2, 2, 3, 3, 5].
(ii) Comparing factorisations to find GCD: To find the GCD, identify the prime bases that appear in both factorisations. For each common prime base, take the minimum of the exponents it has in the two representations. Multiply these resulting prime powers together to get the GCD.

Maths • 01
Polynomials & All 10 Standard Algebraic Identities
  • Identity I (Square of a Binomial Sum): \((a + b)^2 = a^2 + 2ab + b^2\)
  • Identity II (Square of a Binomial Difference): \((a - b)^2 = a^2 - 2ab + b^2\)
  • Identity III (Difference of Squares): \(a^2 - b^2 = (a + b)(a - b)\)
  • Identity IV (Product with Common Term): \((x + a)(x + b) = x^2 + (a + b)x + ab\)
  • Identity V (Square of a Trinomial): \((a + b + c)^2 = a^2 + b^2 + c^2 + 2ab + 2bc + 2ca\)
  • Identity VI (Cube of a Sum): \((a + b)^3 = a^3 + b^3 + 3ab(a + b) = a^3 + 3a^2b + 3ab^2 + b^3\)
  • Identity VII (Cube of a Difference): \((a - b)^3 = a^3 - b^3 - 3ab(a - b) = a^3 - 3a^2b + 3ab^2 - b^3\)
  • Identity VIII (Sum of Cubes): \(a^3 + b^3 = (a + b)(a^2 - ab + b^2)\)
  • Identity IX (Difference of Cubes): \(a^3 - b^3 = (a - b)(a^2 + ab + b^2)\)
  • Identity X (Gauss / Trinomial Cube Identity): \(a^3 + b^3 + c^3 - 3abc = (a + b + c)(a^2 + b^2 + c^2 - ab - bc - ca)\)
  • Special Exam Shortcut: If \(a + b + c = 0\), then \(a^3 + b^3 + c^3 = 3abc\).
  • Remainder Theorem: When a polynomial \(p(x)\) of degree \(\ge 1\) is divided by \((x - a)\), the remainder is \(p(a)\). If \(p(a) = 0\), then \((x - a)\) is a factor of \(p(x)\).

Maths • 03
Coordinate Geometry & Linear Equations in Two Variables
  • Quadrant Sign Rules \((x, y)\): Quadrant I: \((+, +)\) • Quadrant II: \((-, +)\) • Quadrant III: \((-, -)\) • Quadrant IV: \((+, -)\).
  • Points on Axes: Any point on the \(x\)-axis is \((x, 0)\); any point on the \(y\)-axis is \((0, y)\); the Origin is \((0, 0)\).
  • Distance Formula: Distance between \(P(x_1, y_1)\) and \(Q(x_2, y_2)\) is \(PQ = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}\).
  • Distance from Origin: Distance of \(P(x, y)\) from \((0, 0)\) is \(\sqrt{x^2 + y^2}\).
  • Midpoint Formula: The midpoint of segment joining \((x_1, y_1)\) and \((x_2, y_2)\) is \(M = \left(\frac{x_1 + x_2}{2}, \frac{y_1 + y_2}{2}\right)\).
  • Standard Linear Equation in Two Variables: \(ax + by + c = 0\) (where \(a, b\) are not both zero). Its graph is a straight line with infinitely many solutions.
  • Slope-Intercept Form: \(y = mx + c\), where \(m = \frac{y_2 - y_1}{x_2 - x_1}\) is the slope (rate of change) and \(c\) is the \(y\)-intercept.
Maths • 04
Number Systems, Laws of Exponents & Surds
  • Product & Quotient of Powers: \(a^m \cdot a^n = a^{m+n}\)   and   \(\frac{a^m}{a^n} = a^{m-n}\) (\(a \ne 0\)).
  • Power of a Power & Product: \((a^m)^n = a^{mn}\)   and   \((ab)^m = a^m b^m\).
  • Zero, Negative & Fractional Exponents: \(a^0 = 1\),   \(a^{-n} = \frac{1}{a^n}\),   \(a^{m/n} = \sqrt[n]{a^m} = (\sqrt[n]{a})^m\).
  • Laws of Radicals (Surds): \(\sqrt{ab} = \sqrt{a}\sqrt{b}\),   \(\sqrt{\frac{a}{b}} = \frac{\sqrt{a}}{\sqrt{b}}\),   \((\sqrt{a} + \sqrt{b})(\sqrt{a} - \sqrt{b}) = a - b\).
  • Rationalising the Denominator: Multiply numerator and denominator of \(\frac{1}{a + b\sqrt{x}}\) by its conjugate \((a - b\sqrt{x})\) so the denominator becomes \(a^2 - b^2x\).
Maths • 05
2D Perimeter, Area, Heron's Formula & Polygon Geometry
  • Baudhāyana-Pythagoras Theorem: In a right-angled triangle with legs \(a, b\) and hypotenuse \(c\): \(a^2 + b^2 = c^2\).
  • Heron's Formula (Any Triangle with sides \(a, b, c\)): Semi-perimeter \(s = \frac{a + b + c}{2}\);   \(\text{Area} = \sqrt{s(s - a)(s - b)(s - c)}\).
  • Equilateral Triangle (side \(a\)): \(\text{Area} = \frac{\sqrt{3}}{4}a^2\),   Altitude \(h = \frac{\sqrt{3}}{2}a\),   Perimeter \(= 3a\).
  • Quadrilaterals: Parallelogram Area \(= \text{base} \times \text{height}\);   Rhombus Area \(= \frac{1}{2} \times d_1 \times d_2\);   Trapezium Area \(= \frac{1}{2}(a + b) \times h\).
  • Circle, Sector & Ring: Circumference \(= 2\pi r\),   Area \(= \pi r^2\),   Annulus (Ring) Area \(= \pi(R^2 - r^2)\),   Sector Area \(= \frac{\theta}{360^\circ}\pi r^2\).
  • Polygons (\(n\) sides): Sum of interior angles \(= (n - 2) \times 180^\circ\);   Sum of exterior angles \(= 360^\circ\);   Number of diagonals \(= \frac{n(n - 3)}{2}\).
Maths • 06
Probability, Statistics (Data) & Number Sequences
  • Empirical / Classical Probability: \(P(E) = \frac{\text{Number of outcomes favourable to } E}{\text{Total number of possible outcomes}}\), where \(0 \le P(E) \le 1\).
  • Complementary Event: \(P(\text{not } E) = P(\bar{E}) = 1 - P(E)\).
  • Arithmetic Mean (Average): \(\bar{x} = \frac{\sum x_i}{n}\)   (or for frequency table: \(\bar{x} = \frac{\sum f_i x_i}{\sum f_i}\)).
  • Median (Sorted Data of size \(n\)): If \(n\) is odd, \(\text{Median} = \left(\frac{n+1}{2}\right)^{\text{th}}\) term;   if \(n\) is even, \(\text{Median} = \text{Average of } \left(\frac{n}{2}\right)^{\text{th}} \text{ and } \left(\frac{n}{2}+1\right)^{\text{th}}\) terms.
  • Mode & Range: Mode \(=\) most frequently occurring observation;   \(\text{Range} = \text{Maximum Value} - \text{Minimum Value}\).
  • Linear / Arithmetic Sequence: \(n^{\text{th}}\) term \(T_n = a + (n - 1)d\);   Sum of first \(n\) natural numbers \(= \frac{n(n + 1)}{2}\);   Sum of first \(n\) odd numbers \(= n^2\).
Science • 01
Physics: Describing Motion & Three Equations of Motion
  • Speed & Velocity: \(\text{Speed} = \frac{\text{Distance}}{\text{Time}}\) (Scalar, \(\text{m/s}\));   \(\text{Velocity} = \frac{\text{Displacement}}{\text{Time}}\) (Vector, \(\text{m/s}\)).
  • Conversion Shortcut: \(\text{km/h} \xrightarrow{\times \frac{5}{18}} \text{m/s}\)   and   \(\text{m/s} \xrightarrow{\times \frac{18}{5}} \text{km/h}\).
  • Average Speed & Uniform Acceleration Velocity: \(v_{\text{avg}} = \frac{\text{Total Distance}}{\text{Total Time}}\);   for uniform acceleration, \(v_{\text{avg}} = \frac{u + v}{2}\).
  • Acceleration: \(a = \frac{v - u}{t}\)   (SI Unit: \(\text{m/s}^2\); negative acceleration is retardation/deceleration).
  • 1st Equation of Motion (Velocity-Time): \(v = u + at\)
  • 2nd Equation of Motion (Position-Time): \(s = ut + \frac{1}{2}at^2\)
  • 3rd Equation of Motion (Position-Velocity): \(v^2 - u^2 = 2as\)   (or \(v^2 = u^2 + 2as\))
  • Uniform Circular Motion Speed: \(v = \frac{2\pi r}{t}\) (speed is constant, velocity changes continuously due to changing direction).
Science • 02
Physics: Force, Laws of Motion, Gravitation & Pressure
  • Linear Momentum: \(p = m \times v\)   (SI Unit: \(\text{kg}\cdot\text{m/s}\)).
  • Newton's Second Law of Motion: \(F = \frac{\Delta p}{t} = \frac{m(v - u)}{t} = m \times a\)   (SI Unit: \(\text{Newton (N)} = \text{kg}\cdot\text{m/s}^2\)).
  • Impulse: \(J = F \times t = m(v - u) = \Delta p\) (Change in momentum).
  • Law of Conservation of Momentum: \(m_1 u_1 + m_2 u_2 = m_1 v_1 + m_2 v_2\)   (Recoil velocity of gun: \(V = -\frac{mv}{M}\)).
  • Universal Law of Gravitation: \(F = G\frac{M \cdot m}{d^2}\), where \(G = 6.673 \times 10^{-11}\text{ N}\cdot\text{m}^2/\text{kg}^2\).
  • Acceleration due to Gravity & Weight: \(g = \frac{GM}{R^2} \approx 9.8\text{ m/s}^2\);   \(\text{Weight } W = m \times g\);   \(W_{\text{Moon}} = \frac{1}{6}W_{\text{Earth}}\).
  • Free Fall Equations (downward \(+g\), upward \(-g\)): \(v = u + gt\),   \(h = ut + \frac{1}{2}gt^2\),   \(v^2 = u^2 + 2gh\).
  • Pressure, Density & Buoyancy: \(P = \frac{\text{Thrust (F)}}{\text{Area (A)}}\) (\(\text{Pa} = \text{N/m}^2\));   \(\text{Density } \rho = \frac{\text{Mass}}{\text{Volume}}\) (\(\text{kg/m}^3\));   \(\text{Relative Density} = \frac{\rho_{\text{substance}}}{\rho_{\text{water}}}\) (No unit).
Science • 03
Physics: Work, Energy, Power & Simple Machines
  • Work Done by a Constant Force: \(W = F \times s\) (when force is along displacement; \(W = 0\) if \(\theta = 90^\circ\) or \(s = 0\)). SI Unit: \(\text{Joule (J)} = 1\text{ N}\cdot\text{m}\).
  • Kinetic Energy: \(E_k = \frac{1}{2}mv^2 = \frac{p^2}{2m}\);   Work-Energy Theorem: \(W = \frac{1}{2}mv^2 - \frac{1}{2}mu^2\).
  • Gravitational Potential Energy: \(E_p = m \times g \times h\).
  • Law of Conservation of Mechanical Energy: \(E_k + E_p = \frac{1}{2}mv^2 + mgh = \text{Constant}\).
  • Power: \(P = \frac{\text{Work (W)}}{\text{Time (t)}} = F \times v\)   (SI Unit: \(\text{Watt (W)} = \text{J/s}\);   \(1\text{ kW} = 1000\text{ W}\),   \(1\text{ hp} \approx 746\text{ W}\)).
  • Commercial Unit of Electrical Energy: \(1\text{ Unit} = 1\text{ kWh} = 3.6 \times 10^6\text{ Joules}\).
  • Simple Machines & Levers: \(\text{Mechanical Advantage (MA)} = \frac{\text{Load (L)}}{\text{Effort (E)}} = \frac{\text{Effort Arm}}{\text{Load Arm}}\);   \(\text{Efficiency } \eta = \frac{\text{Work Output}}{\text{Work Input}} \times 100\%\).
Science • 04
Physics: Sound Waves, Frequency, Echo & SONAR
  • Frequency & Time Period Relation: \(\nu = \frac{1}{T}\) and \(T = \frac{1}{\nu}\)   (Frequency SI Unit: \(\text{Hertz (Hz)} = \text{s}^{-1}\)).
  • Wave Velocity Equation: \(v = \lambda \times \nu = \frac{\lambda}{T}\)   (where \(v =\) wave speed, \(\lambda =\) wavelength, \(\nu =\) frequency).
  • Echo & SONAR Ranging Formula: Total distance travelled by sound \(= 2d = v \times t \implies d = \frac{v \times t}{2}\).
  • Minimum Distance for Distinct Echo in Air: Since persistence of hearing is \(0.1\text{ s}\) and \(v_{\text{air}} \approx 344\text{ m/s}\) at \(22^\circ\text{C}\), \(d_{\min} = \frac{344 \times 0.1}{2} = 17.2\text{ m}\).
  • Frequency Ranges: Infrasonic: \(< 20\text{ Hz}\) • Human Audible Range: \(20\text{ Hz}\text{ to }20,000\text{ Hz}\) (\(20\text{ kHz}\)) • Ultrasonic: \(> 20\text{ kHz}\).
Science • 05
Chemistry: Solution Concentration, Atomic Structure & Mole Concept
  • Mass by Mass % of a Solution: \(\frac{\text{Mass of Solute}}{\text{Mass of Solution}} \times 100 = \frac{\text{Mass of Solute}}{\text{Mass of Solute} + \text{Mass of Solvent}} \times 100\).
  • Mass by Volume % of a Solution: \(\frac{\text{Mass of Solute}}{\text{Volume of Solution}} \times 100\).
  • Volume by Volume % of a Solution: \(\frac{\text{Volume of Solute}}{\text{Volume of Solution}} \times 100\).
  • Temperature Scale Conversions: \(T(\text{K}) = T(^\circ\text{C}) + 273.15\)   and   \(^\circ\text{F} = \frac{9}{5}(^\circ\text{C}) + 32\).
  • Atomic Number (\(Z\)) & Mass Number (\(A\)): \(Z = \text{Number of protons } (p^+)\);   \(A = \text{Protons } (Z) + \text{Neutrons } (n^0) \implies n^0 = A - Z\).
  • Bohr-Bury Shell Capacity Rule: Maximum electrons in orbit \(n = 2n^2\)   (\(K=2,\; L=8,\; M=18,\; N=32\); outermost shell holds at most \(8\) electrons).
  • Average Atomic Mass of Isotopes: \(M_{\text{avg}} = \frac{(M_1 \times p_1) + (M_2 \times p_2)}{100}\)   (e.g., Chlorine: \(35 \times \frac{75}{100} + 37 \times \frac{25}{100} = 35.5\text{ u}\)).
  • Mole & Avogadro's Constant: \(\text{Number of Moles } (n) = \frac{\text{Given Mass } (m)}{\text{Molar Mass } (M)} = \frac{\text{Number of Particles } (N)}{N_A}\), where \(N_A = 6.022 \times 10^{23}\text{ mol}^{-1}\).
