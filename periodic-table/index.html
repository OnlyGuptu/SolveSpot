Class 9 Chemistry Guide: Bohr-Bury Model, Electron Shells & Valency

Understanding the arrangement of electrons inside an atom is essential for CBSE Class 9 Chemistry (Chapters 8 and 9: Journey Inside the Atom and Atomic Foundations of Matter). Below is the complete reference used by our interactive electron shell visualizer above.

1. Bohr-Bury $2n^2$ Electron Distribution Rule

Electrons revolve around the nucleus in discrete energy levels called shells ($K, L, M, N$), numbered $n = 1, 2, 3, 4$:

  • K-shell ($n = 1$): Max $2(1)^2 = 2$ electrons
  • L-shell ($n = 2$): Max $2(2)^2 = 8$ electrons
  • M-shell ($n = 3$): Max $2(3)^2 = 18$ electrons
  • N-shell ($n = 4$): Max $2(4)^2 = 32$ electrons

2. Octet Rule & Calculating Valency

The outermost shell cannot hold more than 8 electrons (Octet Rule). Valency is the combining capacity of an element:

  • If valence electrons $= 1, 2, 3,$ or $4$: Valency = Valence Electrons (e.g., $\text{Na}$: $2,8,1 \Rightarrow \text{Valency } 1$).
  • If valence electrons $= 5, 6,$ or $7$: Valency = $8 -$ Valence Electrons (e.g., $\text{Cl}$: $2,8,7 \Rightarrow \text{Valency } 1$).
  • If valence shell is complete ($2$ in $\text{He}$ or $8$ in $\text{Ne}, \text{Ar}$): Valency = 0 (Noble Gases).

3. Isotopes, Isobars & Atomic Numbers

Atomic Number ($Z$) equals the number of protons inside the nucleus. Mass Number ($A$) is the sum of protons and neutrons ($A = Z + n$).

  • Isotopes: Same $Z$, different $A$ (e.g., Protium $^1_1\text{H}$, Deuterium $^2_1\text{H}$, Tritium $^3_1\text{H}$; Carbon-$12$ & Carbon-$14$).
  • Isobars: Different $Z$, same $A$ (e.g., Argon $^{40}_{18}\text{Ar}$ & Calcium $^{40}_{20}\text{Ca}$).
